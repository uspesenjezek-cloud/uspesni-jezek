# Vzorci NAP (nap.si)

Datoteke `nap-real-*.xml` so skrajšani uradni vzorci z nap.si (gumb »vzorec« pri
posameznem viru), objavljeni pod licenco CC BY-SA 4.0
(https://creativecommons.org/licenses/by-sa/4.0/deed.sl). Izdajatelj: Ministrstvo
za infrastrukturo / NCUP (DARS, DRSI). Uporabljeni so samo za teste bralnika
DATEX II v3.3. Skrajšani so na nekaj elementov; struktura je nespremenjena.

Datoteke `nap-*.xml` brez »real« so ročno sestavljeni primeri po standardu.
